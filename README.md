# AI-Powered Waste Management Platform

Zero2Hero is an AI-integrated waste management platform designed to encourage responsible waste reporting and collection. Powered by **Next.js 14**, **Google Gemini AI**, and a modern web stack, it gamifies eco-friendly actions through rewards, real-time updates, and community-driven engagement.


---

## 🚀 Features

- ✅ **AI-Powered Waste Verification** using Google's Gemini AI
- 🏆 **Reward System** to incentivize user participation
- 🔁 **Real-Time Waste Task Management**
- 📈 **Leaderboard** for community competition
- 📱 **Responsive UI** with Tailwind CSS
- 🔐 **Secure Authentication** using Web3Auth
- 🗃️ **Modern Database Integration** with Drizzle ORM and Neon

---

## 🛠️ Tech Stack

| Tech           | Role                            |
|----------------|---------------------------------|
| Next.js 14     | Frontend & Backend Framework    |
| TypeScript     | Strongly-Typed Language Support |
| Tailwind CSS   | UI Styling                      |
| Gemini AI      | Waste Image Verification        |
| Drizzle ORM    | Type-safe Database ORM          |
| Neon           | Serverless Postgres Database    |
| Web3Auth       | Authentication Service          |
